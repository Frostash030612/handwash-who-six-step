## 消融实验设计（E3，对应研究问题 3）

固定：数据、划分、seed、骨干、训练轮数。只改后处理方式：

| 组 | `model.temporal.kind` | `train.mode` | `infer.temporal_apply` | 回答的问题 |
| --- | --- | --- | --- | --- |
| A | none | frame | false | 纯单帧基线的下界 |
| B | none | frame | true | 仅概率平滑能否减少跳变 |
| C | mean_pool | clip | true | 训练时有时序结构但无时序建模 |
| D | gru（或 tcn） | clip | true | 本方案 |

报告里除 Accuracy / Macro-F1 外，**必须给出"帧级跳变次数"或"分段数"**——
否则无法直接说明"时序处理减少了单帧误判"。建议统计：

```
跳变次数 = 平滑前后 标签序列中相邻帧标签变化的次数
```

（可用 `handwash evaluate --splits test` 产出的 `predictions_*.jsonl` 计算并画图。）
