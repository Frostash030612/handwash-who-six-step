# 自采场景整段解码 v4：边界误报优化

2026-10-20。在固定 v3 多尺度边界模型上完成解码优化与云端复测。
当前优先用于新独立视频评估的方案为：
**自采 YOLO＋冻结 GRU＋多尺度边界头＋整段解码**。

## 改动与原因

旧模型在视频 4、8 上每个种子均检出 14 个真实边界、漏检 0 个，却产生
22～23 个假边界。短暂分类跳变和换手附近的误判导致过度分段。
v3 的三个种子中有两个选择了原始分类输出，边界头的改善没有充分进入最终解码。

v4 使用整段视频的动态规划，为每个候选动作段累加原始类别对数概率，
并在切换类别时加入代价。低边界概率进一步增加切换代价；高边界概率
只能降低这项附加代价，不能奖励凭空切段。

```text
段得分 = 段内类别对数概率之和
       − 每次切换的固定代价
       − 边界权重 × 截断后的 −log(边界概率)
       − 可选的短动作软惩罚
```

全部七类和任意类别顺序均可出现，不使用正常洗手顺序、测试标签或已知动作数量。
算法仍允许强分类证据支持的短动作。others 与视频两端可能被截断的动作
不受短动作惩罚。解码保留原始概率作为证据，不把输出标签转成 100% 置信度。

**验证集最终选择的短动作软惩罚系数是 0**，所以本轮实际收益来自整段分类
证据、切换代价和边界辅助；不能宣称“强制三秒分段”有效。
最终动作链仍沿用 1 秒居中平滑、连续至少 3 秒确认，较短片段标为未确认。

## 固定协议

- 使用原 14 段训练得到的 YOLO 与三个 GRU，以及 v3 的三个多尺度边界头。
  本轮不更新网络参数。YOLO 特征仍为实际 1088 输入、5 fps。
- 验证视频为 10、12、14、16、18、20、22、24；回归视频为 4、8。
- 预先固定 27 组解码设置：切换代价 1/3/6，短动作代价 0/2/4，
  边界权重 0/0.5/1。边界负对数代价上限为 4。
- 有边界、无边界两族分别按三个种子的平均验证综合分数选择，
  各族三个种子共享一组设置。综合分数仍为 40% 宏 F1＋30% 连续视频动作链匹配率＋30% 边界 F1。
- 并列时依次取较高宏 F1、较高边界 F1、较低边界权重、较低短动作代价、较低切换代价。
- `selection.json` 写盘后才读取回归预测，回归结果不参与选择。
- 新采集的 10 段视频未使用。现有验证集与回归视频都已反复检查，本轮属于内部结果。

两族选中的设置：

| 项目 | 无边界对照 | 有边界方案 |
|---|---:|---:|
| 切换代价 | 3 | 3 |
| 边界权重 | 0 | 0.5 |
| 短动作软惩罚 | 0 | 0 |

这是离线整段解码，会使用后续帧证据，不能按零延迟实时方案宣传。

## 结果

以下为视频 4、8 的三个种子均值。最终解码边界 F1、WHO 片段 F1@50、
边界头自身 F1 是不同指标；本轮没有改变边界头，不能把解码改善称为边界头训练改善。

| 方案 | 帧准确率 | 宏 F1 | 最终解码边界 F1 | WHO 片段 F1@50 | 确认动作链 |
|---|---:|---:|---:|---:|---|
| 原始普通 GRU | 95.28% | 95.00% | 53.27% | 50.79% | 各种子 2/2 |
| v3 多尺度模型原解码 | 95.53% | 95.29% | 55.27% | 52.73% | 各种子 2/2 |
| v4 无边界对照 | 95.97% | 95.71% | 84.07% | 76.48% | 各种子 2/2 |
| **v4 有边界方案** | **96.92%** | **96.83%** | **89.44%** | **83.41%** | **各种子 2/2** |

验证集的有边界、无边界方案汇总指标相同：帧准确率 99.57%、宏 F1 99.51%、
边界 F1 99.07%、WHO 片段 F1@50 96.55%；连续视频动作链均为 4/4，
单动作视频单列也均为 4/4。因此独立验证中是否存在稳定的边界附加收益仍待检验。

同一 v4 有边界配置把边界权重置零后，回归边界 F1 从 89.44% 降至 84.07%，
帧准确率从 96.92% 降至 95.97%。该对照与独立选择的无边界方案恰好相同，
支持本批回归视频中存在边界辅助收益。

| 种子 | v3 假边界 | v4 假边界 | v4 漏边界 | v4 边界 F1 | v4 帧准确率 |
|---|---:|---:|---:|---:|---:|
| 20261018 | 23 | 4 | 0 | 87.50% | 96.60% |
| 20261019 | 23 | 4 | 0 | 87.50% | 96.60% |
| 20261020 | 22 | 2 | 0 | 93.33% | 97.55% |

每个种子均保留 14 个真实边界。边界时间误差均值从 v3 的 0.01730 秒降至
0.01266 秒；这是预测超出标注过渡区间的距离，区间内记零，不是精确切换时刻误差。
边界一对一匹配规则与额外 0.4 秒容差保持不变。
开头 others 为 102/102、结尾 others 为 72/72（三种子合计）。

有边界方案在验证和回归上均通过此前规定的内部替换门槛：准确率、宏 F1、
动作链匹配率、边界 F1 不降低，至少一项改善，边界时间误差不增加。
无边界对照的回归时间误差略增，未完全通过门槛。尚未替换演示应用或完成独立测试。

## 仍然存在的错误

- 视频 8 的约 41.18～44.01 秒仍有动作 6 被判成 4/3，具体范围随种子而变。
  v4 减少了其中来回跳变，但不能凭解码恢复网络缺失的视觉证据。
  个别错误片段会被合并成更连续的错误段，例如一个种子的约 1 秒动作 4
  误判延长到约 2 秒；更少切换不等于每个局部片段都变好。
- 种子 20261018 在视频 4 的约 50.79～51.57 秒仍将动作 6 判作 others，
  形成约 1 秒背景段。
- 个别动作切换附近仍存在约 0.2 秒的错误。逐视频错误区间和原始类别置信度
  保存在 `per_video.json`，不能用动作链 2/2 代替逐帧无错。
- 参考数据不足以验证各种真实短动作和所有换手情况。新增数据应包含自然换手、
  真实乱序和停顿；独立测试标签在看模型预测之前完成。

## 实现、检查与复现

- 核心：`src/handwash/core/segment_decoding.py`。
- 参数：`configs/research/self_scene_segment_v4.yaml`。
- 选择和评估：`scripts/evaluate_self_scene_segment_v4.py`。
- GPU 重放与推理包：`scripts/verify_self_scene_segment_v4.py`。
- 核心算法与相关边界/动作链单元检查 33 项通过，其中包含小序列穷举最优性、
  任意乱序和重复、短背景保留、假边界不凭空切段、强证据短动作保留。
- 在 RTX 3090 上重新前向三个冻结模型、共 30 个模型/视频组合，
  v4 解码标签与缓存评估全部一致；源权重指纹保持不变。

```bash
python scripts/evaluate_self_scene_segment_v4.py \
  --source /root/autodl-tmp/handwash_self_scene_refresh_20261019/structure_v3_20261020 \
  --output /root/autodl-tmp/handwash_self_scene_refresh_20261019/segment_v4_20261020

python scripts/verify_self_scene_segment_v4.py \
  --source /root/autodl-tmp/handwash_self_scene_refresh_20261019/structure_v3_20261020 \
  --feature-cache /root/autodl-tmp/handwash_self_scene_refresh_20261019/boundary_v2_20261020/features \
  --yolo /root/autodl-tmp/handwash_self_scene_refresh_20261019/models/yolo_best.pt \
  --result /root/autodl-tmp/handwash_self_scene_refresh_20261019/segment_v4_20261020
```

输出包括 `selection.json`、完整验证网格、三种子结果、逐视频错误、逐帧原始概率
和新标签、GPU 重放记录。`inference_bundle/` 保存三个原始网络检查点、冻结 YOLO
和新的解码配置。三个种子是独立实验，不是集成；使用时必须读取
`manifest.json` 中的 v4 解码配置，不能继续使用旧检查点内嵌的 v3 解码设置。

原始数据与权重按仓库规则在本地/云端保存，Git 仓库仅保存代码、配置和结果文档。
