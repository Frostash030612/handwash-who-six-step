# 最终技术版本 2026-10-22

本版本固定当前技术成果。主方案为 **YOLO＋自适应边界感知 GRU**；YOLO、YOLO＋GRU
作为结构对照，VideoMAE 作为离线精度参照。这次只归档现有代码、权重、标注与结果，
不重训、不调参、不新增实验。

## 固定内容

- 七类：其他＋六个洗手动作；见[标签表](final_release/label_map.json)。
- YOLO26m-cls 使用 1088 输入，沿用先等比例缩放并复制边缘填充至 1080 的摄像头预处理。
- GRU 特征维度 1280、隐藏维度 128、dropout 0.3；边界头为单向 GRU＋边界分支。
- 边界解码阈值 0.3、峰间距 4 个采样点；仅边界模型使用自适应动作链确认，
  固定 1 秒多数平滑、异常阈值 -2、至少 4 个可比较片段，并结合置信度。
- VideoMAE 使用通用 Kinetics 预训练、224 输入、16 帧窗口、5 fps、4 帧步长。
- 当前四模型的自采训练不使用 PSKUS 数据或 PSKUS 权重。
- 单次只运行选定模型；停止后汇总已有预测。六步顺序正确且预测洗手总时长至少 40 秒才达标。
  其他和未知时间不计入，不要求每个动作分别达到某个秒数。
- 本机入口优先 Apple MPS，否则 CPU；未提供 CUDA 选择。

## 训练过程的归档说明

共 32 段自采视频：开发阶段 14 段训练、8 段验证，另有 10 段测试（原视频 4、8＋新增 8 段）。
YOLO 骨干与 VideoMAE 按 14／8 划分训练和选模。

**保留的时序头训练脚本表明：普通 GRU 与边界 GRU 先用 14／8 选择轮数和解码参数，
随后重新初始化，在 22 段开发视频上重训，并用这 22 段计算特征标准化。**
当前检查点的选择轮数为 GRU 5、边界 GRU 3，文件哈希与十视频 YOLO 系列评估记录一致。
检查点本身未包含完整训练视频 ID 列表，因此同时保留训练脚本作为来源证据。
不能把本版写成“四模型严格都只用相同 14 段训练”，也不能当作只改变网络结构的严格消融。
脚本的最终训练列表不包含测试视频。现有模型保持不变。

## 最终结果的唯一引用口径

报告采用[四模型最终对比](SELF_SCENE_FOUR_MODEL_COMPARISON.zh-CN.md)、
[指标表](final_release/metrics.csv)和[逐视频动作链](final_release/action_chains.csv)。
这是 2026-10-21 已保存的结果，不是本次整理新跑出的成绩。

| 模型 | 准确率 | 宏 F1 | 输出边界 F1 | 最终动作链 |
| --- | ---: | ---: | ---: | ---: |
| YOLO | 95.25% | 93.84% | 76.92% | 2/10 |
| YOLO＋GRU | 96.04% | 93.58% | 87.59% | 6/10 |
| YOLO＋自适应边界感知 GRU | 96.52% | 93.71% | 94.40% | 10/10 |
| VideoMAE | 99.53% | 99.02% | 97.48% | 10/10 |

分类、输出边界指标使用 632 个共同有效时间点；只有边界模型的最终动作链使用
5 fps 完整预测的自适应确认，其他模型使用共同时间点的原始类别链。
十视频已被反复查看，视频 8 的标注曾在看到预测后更正，不能宣称新场景独立泛化成绩。
视频 8 最终顺序为 124536，29 秒开始动作 5。不同输入、训练过程及后处理共同影响结果。

权重内的旧 metrics 字段是早期两段视频与旧标注下的成绩，不用于最终报告。
不为更新这些字段改写权重文件。VideoMAE 内部精度最高，但窗口造成反馈延迟；
它能流式更新，不能写成“本地无法部署”。现有短时结构测速不代表持续负载、功耗或独立峰值内存结果。

## 运行

关键依赖按[现有环境记录](final_release/deployment_environment.json)固定版本。先安装 Python 3.12。解压后在包目录执行：

```sh
PYTHON_BIN=python3.12 bash install.sh
.venv/bin/python start_camera.py
```

Windows 安装入口为 `install.ps1`，启动使用 `.venv\Scripts\python.exe start_camera.py`。
本次归档环境为 macOS，没有重新验证 Windows 部署。安装依赖需要网络，推理使用包内权重。
浏览器打开 http://127.0.0.1:8876/ 并授权摄像头。端口占用时可用 `--port 8877`。

`python verify_files.py` 只核对包内文件是否完整。复算已保存指标的命令见
[英文完整说明](FINAL_RELEASE.md)，无需重训或重新推理。
