# 自采视频拍摄与标注规范（SELF_RECORDING）

自采视频是本项目**最有说服力的验证材料**：答辩时现场拍一段，模型当场给出判定，
结果可以直接被人眼核对。但前提是拍摄与标注方式统一，否则无法作为对照。

---

## 1. 拍什么（每人 4—6 段，缺一不可）

| 编号 | 类型 | 要求 | 用途 |
| --- | --- | --- | --- |
| A | **完整正确** | 六步齐全、顺序正确、总时长 40—60 秒 | 验证不误报 |
| B | **漏一步** | 任选一步不做（记录是哪一步） | 验证漏步检出 |
| C | **换序** | 交换相邻两步（例如先 3 后 2） | 验证乱序检出 |
| D | **某步过短** | 某步只做 1—2 秒 | 验证时长不足检出 |
| E | （可选）**环境变化** | 换衣服 / 光照 / 背景 / 角度 | 验证鲁棒性 |
| F | （可选）**遮挡** | 手被身体或袖子部分挡住 | 记录失败案例 |

每段视频**必须**只有一个变化因素。A 段永远是基准，其余段与 A 对比才说明问题。

## 2. 怎么拍

- **机位**：俯拍或侧前方 45°，双手**全程清晰可见**，不要只拍到手背或指尖。
  参考公开数据集的机位（`docs/DATA.md`），这样与训练分布差异更小。
- **构图**：手在水龙头下方的位置基本固定；不要频繁走出画面。
- **时长**：单段 30—70 秒。太短（<15 秒）时长判定会失真。
- **稳定性**：手持可以，但避免剧烈晃动（会引起运动模糊）。
- **分辨率**：≥ 720p；帧率 ≥ 25 fps（抽帧到 5 fps 后仍有足够样本）。
- **命名**：`<姓名拼音>_<类型><序号>.mp4`，例如 `zhangsan_A01.mp4`、`zhangsan_B01.mp4`。
- **存放**：`data/external/self_recorded/full/`（整段视频评估用这个目录）。

## 3. 标注（人工答案 = ground truth）

拍完立刻填下面这张表（**不要事后凭记忆补**）。这张表就是评估用的
`ground_truth.csv` 来源。

CSV 格式（列名固定）：

```csv
clip_id,steps,expected_complete,expected_in_order,notes
zhangsan_A01,1;2;3;4;5;6,true,true,基准段
zhangsan_B01,1;2;3;5;6,false,true,漏第 4 步
zhangsan_C01,1;3;2;4;5;6,true,false,第 2、3 步互换
zhangsan_D01,1;2;3;4;5;6,true,true,第 6 步仅 1 秒
```

- `clip_id`：与视频文件名（不含扩展名）**完全一致**；
- `steps`：实际执行的步骤序号，用 `;` 分隔，按时间顺序；
- `expected_complete`：是否六步齐全（`true`/`false`）；
- `expected_in_order`：顺序是否正确（`true`/`false`）；
- `notes`：一句话说明该段的特点。

## 4. 评估命令

```bash
# 逐段出中文报告（JSON + Markdown）
python scripts/run_assess.py --folder data/external/self_recorded/full \
    --ground-truth data/external/self_recorded/ground_truth.csv

# 或单段
python -m handwash.cli assess --video data/external/self_recorded/full/zhangsan_A01.mp4
```

产物：
- `outputs/<run>/assess/<clip>.md`：可直接贴进报告的单段报告
- `outputs/<run>/assess/assess_summary.csv`：全部视频的汇总表
- `outputs/<run>/assess/assess_vs_ground_truth.csv`：与人工答案的逐段对比

## 6. 报告里怎么写这一节

建议结构：

1. **拍了几段、谁拍的、什么设备**（说明数据来源的可靠性）；
2. **人工答案 vs 模型判定**的对比表（引用 `assess_vs_ground_truth.csv`）；
3. **完整性/顺序判断准确率**两个数字；
4. **失败案例 2 个以上**：贴出模型判错的那一段，说明原因
   （例如"第 6 步指尖动作与第 4 步指背动作在俯拍角度下视觉相似"）；
5. **结论**：在真实家庭环境下系统可用到什么程度，还差什么。

> 第 4 点最重要。**只报成功的部分不会被当成严谨的工作**；
> 说清楚"什么情况下会失败、为什么"才是。

## 7. 隐私与伦理

- 拍摄前取得被拍者同意；视频只用于本课程作业，不公开传播。
- 不要拍到他人面部或可识别的个人信息；能只拍手部就只拍手部。
- `data/` 目录不进 Git（已在 `.gitignore`），分享时用移动硬盘或共享盘。
- 本系统**不做医学判断**，报告中不得表述为"消毒合格 / 不合格"。
