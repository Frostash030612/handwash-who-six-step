# 双击启动器（scripts/launchers/）

给**不熟悉命令行**的成员用的入口：双击一下，就把数据从零跑到"可以发给队友的分享包"。

| 系统 | 双击这个 |
| --- | --- |
| **Windows** | `一键出结果.bat` |
| **macOS** | `一键出结果.command` |
| Linux | 在终端里跑 `bash 一键出结果.command`，或直接用命令行脚本 |

真正的逻辑不在这些启动器里，它们只做三件事：切到仓库根目录、打印说明、调用
`one_click_dataset.py` → `scripts/bootstrap_dataset.py`。

---

## 双击之前先知道三件事

1. **会下载约 17 GB**（PSKUS 全集，11 个分片）。开始前脚本会先检查磁盘空间，
   不够会直接告诉你。
2. **中途关掉窗口没关系**。已经下好的分片、已经抽好的帧都会被记录，
   下次双击自动从断点继续 —— 不需要清理任何东西，也不要手动删文件。
3. **必须下全 11 个分片，产出的划分才能给全组使用**。只下了一部分时脚本会
   **主动中止**，并告诉你两条出路：再双击一次补齐，或加 `--allow-partial`
   先验证链路（那样产出的划分不可用于正式实验）。

第一次运行建议先读一遍 [`docs/DATA_COLLABORATION.md`](../../docs/DATA_COLLABORATION.md)
第 3.0 节，那里解释了为什么只传抽帧结果而不是原始数据（上传量从 17 GB 降到 2.8 GB）。

---

## 结束后要做什么

双击跑完会打印一段「交接清单」，照着做即可：

1. 把清单里列出的**三个文件**传到网盘（`.zip` / `.zip.sha256` / `_package.json`）
2. 把链接发到群里
3. 队友下载后运行清单里给的三条命令（`--verify` → `--unpack` → 训练）

---

## 启动器为什么分两个文件

一开始试过把 `.bat` 和 Python 写进同一个文件（多语言混写）。结论是**不可行**：
cmd.exe 按系统代码页读取源文件，中文注释会被截断成乱码，行结构随之破坏，
于是出现 `'网盘分享给队友' is not recognized as an internal or external command`
这类把正文当命令执行的诡异报错。

现在拆成"启动器 + Python 入口"两个文件，并遵守三条硬规则：

| 规则 | 原因 |
| --- | --- |
| `.bat` 必须是 **CRLF** 换行 | cmd.exe 按行解析，LF-only 会把多行粘成一行 |
| `.bat` 必须是 **UTF-8 with BOM** | 没有 BOM 时 cmd 按系统代码页（GBK/936）读取，中文变乱码 |
| `.bat` 只用 `@REM` 注释 | `#` 在部分情况下会被 cmd 当成命令的一部分 |

`.bat` 由 `.tmp` 下的一次性生成脚本写出（保证字节确定）。如果 `.bat` 显示乱码或报
"不是内部或外部命令"，检查这三点：文件应以 `EF BB BF` 开头，且不含单独的 LF。

---

## 需要更多选项时

双击入口**刻意不支持** `--shards` / `--skip-*` 等参数：双击的人不一定读参数说明，
留了选项就可能出现"只下了一半分片就产出划分"这类**不会有任何报错**的错误。
需要变体时请直接用命令行脚本：

```bash
python scripts/bootstrap_dataset.py --help
```
